Exploratory Data Analysis & Project Workflow

1. Data Collection & Processing

To support robust recommendations, we collected and integrated external datasets spanning major professional educational platforms (including Udemy, Coursera, EdX, and Online Courses) with a total dataset repository of thousands of computer science courses. The data ingestion engine filters courses using descriptive heuristics to eliminate unrelated fields (such as cooking or finance) and stores unified records in a local dataset.

2. Information Retrieval (IR) Framework

The recommendation engine uses a mathematical TF-IDF Vector Space Model combined with Cosine Similarity Ranking. When a student inputs a search query, it is dynamically tokenized and transformed into a term-frequency vector. Cosine similarity coefficients are calculated across the entire document corpus to return highly relevant course results.

3. Neural Network & Visualizations

Course-to-course relationships are built using pairwise cosine similarity vectors. Pairs with similarity weights exceeding a threshold of 0.13 are compiled into a D3-based force-directed networking graph. This enables organic node-clustering of computer science topics (like Web Dev, AI/ML, and Cybersecurity) in an interactive visual interface.

4. LLM Study Plan Orchestrator

The generative path planner uses Gemini-2.5-Flash acting as an expert academic advisor. It maps the IR search findings directly to the student's career target, composing a highly customized week-by-week learning syllabus, complete with descriptive explanations and weekly hands-on practical exercises.
